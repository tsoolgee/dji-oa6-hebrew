# אקשן 6 בעברית — סימולטור מסכי DJI Osmo Action 6

דף HTML יחיד שנראה כמו המצלמה: גוף, לחצנים, המסך האחורי והמסך הקדמי. כל לחיצה והחלקה עובדות כמו במצלמה, וכל תפריט מתורגם לעברית. השם באנגלית מופיע קטן, והתרגום גדול.

## מבנה
- `src/data.js` — עץ התפריטים (כ-165 פריטים), תרגום ורמת ודאות לכל פריט
- `src/app.js` — המסכים, ההחלקות והלחצנים
- `src/feed.js` — תמונה חיה בקנבס שמגיבה לייצוב, צבע, חשיפה וזום
- `src/icons.js` — אייקוני הממשק
- `src/screen.css`, `src/template.html` — עיצוב ופריסה
- `images/` — התמונות. הדף טוען אותן מ-jsDelivr ולא מטמיע אותן
- `tools/` — סקריפטי תיקון שהוחלו במהלך הכיול מול צילומי מסך אמיתיים

## בנייה
```
python build.py
```
הבנייה יוצרת את `dist/index.html`, קובץ אחד שעובד בכל דפדפן.
